Config Builder

Choose a setup and this writes the file. Every option is one the parser accepts and every number is checked against the constraint Config::validate applies, so a file this page hands you loads.

Nothing leaves your browser. The document is assembled here as you type. The Configuration Reference is the same schema written out, and Python: TOML File shows what to do with the result.

Objective [fitness]

What a graph is scored on. Three of these read one SIR simulation differently and share its parameter block.

Objective typerequired

Per-edge, per-timestep. Too low and every graph scores alike.

Fitness is their average.

Patient zero and short-outbreak re-rolls — all default, omitted unless changed

A node index, so below network_size. Leave blank to draw fresh.

Shorter outbreaks are re-simulated. 1 disables it.

Attempts before keeping whatever came out.

Newly-infected per timestep, compared verbatim — nothing is prepended for patient zero and nothing is rescaled, so give it at the size of network you are building.

One edge list per graph — start,end,weight per line, and a # nodes = N header on every file. Not opened until the objective is built, so a wrong path fails at run rather than here.

Bins, bandwidths and family weights — all default, omitted unless changed

Three statistic families — degree, clustering, spectral — each binned, each with an RBF bandwidth, each weighted. A weight of 0 switches its family off; they cannot all be 0. Bandwidths that are too large collapse every score to zero, which looks like a healthy run searching nothing.

Distance from the reference set's mean density. 0 switches it off.

Nothing else goes in the file. The objective's parameters belong to your callable. Register it before the run with evolver.set_fitness_function(callable, direction) — it takes a batch of graphs and returns one float per graph.
