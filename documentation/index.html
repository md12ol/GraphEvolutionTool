Graph Evolution Tool

Evolve networks against an epidemic

GET searches for graphs that make a simulated disease behave in a particular way — spread as far as possible, last as long as possible, or trace a particular infection curve. You describe the experiment in a config file or in Python; GET runs an evolutionary algorithm in Rust and hands back the best network it found, plus the convergence log that produced it.

Python: config objects →

Build a run out of typed objects and read the results back as Python values. No file to maintain.

Python: TOML file →

Keep the parameters in a document you can archive, diff and hand to someone else.

Rust: as a library →

Depend on the crate, write your objective as a Rust type, drive an evolver directly.

Rust: the get-run CLI →

One command, one config file, three output files. No interpreter in the loop.

The idea in one picture

Everything in GET is a loop around four things. A genome is a compact recipe. Expressing it produces a graph. Running epidemics on that graph produces a fitness number. An evolver uses those numbers to decide which genomes get to have children, and the loop goes round again.

What you get to choose

AxisOptionsWhere
Representation edge-edit — a script of edits over a starting graph · SDA — an automaton that writes a graph from scratch [genome] type
Strategy generational — replace everyone each round · steady-state — one mating at a time [evolution] type
Objective epi_spread · epi_length · epi_prof_match · or your own, in Python or Rust [fitness] type
Selection tournament [selection] type

A complete run

import get

config = get.Config(
    evolution       = get.EvolutionConfig.Generational(num_generations=500, elite_count=1),
    population_size = 200,
    network_size    = 100,
    crossover_rate  = 0.9,
    mutation_rate   = 0.2,
    selection       = get.SelectionConfig.Tournament(tournament_size=5),
    genome          = get.GenomeConfig.EdgeEdit(gene_length=256),
    fitness         = get.FitnessConfig.EpiSpread(
        sir = get.SirParams(infection_rate=0.05, num_epidemics=30)
    ),
)

evolver = get.GraphEvolver.from_config(config)
result  = evolver.run(20260812)      # one master seed drives everything

print(result.best_fitness)           # nodes infected, in your units
print(len(result.best_edges))        # the winning network, as (u, v, weight) triples
print(len(result.history))           # the convergence log, one row per generation
